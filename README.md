# Smart Goval — AI-Powered Legal & Compliance Assistant

An Android application that uses **Gemini AI** to help users analyze legal documents, generate contracts, detect risk clauses, and get instant legal guidance — all from their phone.

---

## Features

### Document Analysis
Upload any legal document and analyze it using 6 AI-powered modules:
- **Contract Summarizer** — Get a plain-language summary of any contract
- **Risk Clause Detector** — Identify potentially harmful clauses
- **Confidentiality Clause Tracker** — Spot NDAs and confidentiality terms
- **Jurisdiction Identifier** — Determine applicable legal jurisdictions
- **Compliance Checker** — Verify regulatory compliance
- **Obligation Extractor** — Extract all obligations and deadlines

### AI Contract Generator
Provide details for two parties via a structured form and let Gemini AI draft a legally structured contract. Contracts can be exported and saved as PDF.

### Custom Clause Builder
Generate specific legal clauses (e.g., termination, liability, indemnity) using AI — tailored to your exact requirements.

### Legal Chatbot
An AI-powered chatbot trained to answer legal questions only — keeping conversations focused and relevant.

### History & Tracking
- View past document analysis results
- Track previously generated clauses
- All history synced via Firebase Firestore

## Getting Started

1. Clone the repository
```
git clone https://github.com/FiazZafar/Ai-Powered-Legal-Compliance-Solution.git
```
2. Open in Android Studio
3. Add your `google-services.json` file for Firebase
4. Add your Gemini API key in the project constants
5. Run on emulator or physical device (Android 7.0+)
